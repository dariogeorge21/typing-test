# Typing Test

A clean and modern browser-based typing speed test with real-time feedback and a result chart.

## Features

- 30-second typing challenge
- Live WPM tracking
- Accuracy calculation
- Adjustable text size (A- / A+)
- Smooth results view with WPM + accuracy chart
- Keyboard-first restart (` key)
- Responsive, minimal, aesthetic UI

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- [Chart.js](https://www.chartjs.org/) (CDN)

## Run Locally

No build step is required.

1. Clone the repository.
2. Open `/home/runner/work/typing-test/typing-test/index.html` in your browser.

You can also use a local static server if preferred.

## How to Use

1. Start typing to begin the timer.
2. Track your WPM and time remaining at the top.
3. Use **A-** and **A+** to adjust text size.
4. Press the **`** key anytime to restart.
5. At the end, review your WPM, accuracy, and chart.
